# Architecture Decision Records (ADR)

This directory stores Architecture Decision Records for the AI Engineering OS framework.

## Purpose

ADRs capture important system design decisions, the alternatives considered, and the rationale behind the chosen approach.

## When to Add an ADR

- When a design decision affects architecture, components, or developer workflow
- When there are multiple implementation options and a tradeoff must be documented
- When a decision is made that should be reviewed later or referenced by other agents

## File Naming

Use a simple incremental format:

- `0001-record-architecture-decision.md`
- `0002-add-sdlc-gating.md`

## Recommended Structure

Each ADR should include:

- Title
- Status
- Context
- Decision
- Consequences
- Related documents
